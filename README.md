# Personalized Beauty Product Recommendation



## Project Description

This project is about analyzing the features of beauty products, customers’ preferences, their ratings and reviews to discover how a personalized beauty product recommendation service might be engineered.

## Background



Beauty products are characterized by a diverse range of ingredients, price lists, brands, purposes, and other features making it hard for customers to find products that are perfect for their needs. The current work discovers how data science might be applied to address this challenge.



## Objectives

1. To study customers’ preferences using ratings and reviews;

2. To analyze product features including product category, brand, price, ingredients;

3. To discover associations and correlations between product features;

4. To conduct a sentiment analysis of customers’ reviews;

5. To study product recommendation methods.



## Datasets Description

1. Sephora Products and Skincare Reviews: https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews



2. Cosmetics Datasets: https://www.kaggle.com/datasets/kingabzpro/cosmetics-datasets



## Tools

1. Python programming language;



2. Pandas, Matplotlib, and Seaborn libraries;

3. Scikit-learn;

4. Jupyter Notebook or Google Colab.

## Tasks

1. Preprocess the data;

2. Perform EDA and data visualization;

3. Study product features in terms of products’ ratings;

4. Analyze customers’ reviews;
